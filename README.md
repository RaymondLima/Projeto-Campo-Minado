# 💣 Projeto Campo Minado

Uma implementação estruturada do clássico jogo Campo Minado, desenvolvida inteiramente em Python. Este projeto tem como objetivo aplicar conceitos de lógica de programação, manipulação de matrizes e construção de interfaces gráficas (GUI).

## ✨ Funcionalidades

* **Interface Gráfica Intuitiva:** Construída utilizando a biblioteca nativa `tkinter`.
* **Níveis de Dificuldade:**
  * **Fácil:** Tabuleiro 9x9 com 10 minas.
  * **Médio:** Tabuleiro 16x16 com 40 minas.
* **Mecânicas Clássicas:** 
  * Revelação de espaços vazios em cascata.
  * Contagem de minas adjacentes.
  * Condições de vitória e derrota com alertas interativos.

## 🛠️ Tecnologias Utilizadas

* **Python 3**
* **Tkinter** (Biblioteca padrão do Python para interfaces gráficas)
* **Random** (Para a distribuição aleatória e imprevisível das minas)
